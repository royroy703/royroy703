## Proyectos desarrollados

### 01 · Portal de asistencia en Odoo

**Un portal para registrar y consultar la asistencia de empleados.**

- Registro de entrada desde el portal.
- Consulta del historial de asistencia.
- Reportes con empleado, entrada, salida y horas.
- Trabajo sobre las vistas y plantillas del módulo.

**Mi participación:** desarrollo desde cero con apoyo de IA.

### 02 · Integración de Odoo con Power BI

**Una conexión para llevar datos de Odoo a un entorno de análisis.**

- Exposición de datos de Odoo mediante una API.
- Respuestas en formato JSON.
- Conexión e importación desde Power BI.
- Preparación de los datos con Power Query.

**Mi participación:** desarrollo de la conexión desde cero con apoyo de IA.
